# 画面仕様

確認画面の項目定義です。構成要素は **14ファイル**（TypeScript と Vue の合計）。
遷移は [screen-transition.md](screen-transition.md)、実装の指針は
[frontend-architecture.md](frontend-architecture.md) を参照してください。

## 1. 画面の一覧

| 画面 | ファイル | 役割 |
| --- | --- | --- |
| 器 | `src/client/App.vue` | テーマの決定、降りものの出し分け、ログイン状態での切り替え |
| ログイン | `src/client/pages/views/login-view.vue` | gkill のアカウントで入る |
| 提案 | `src/client/pages/tag-suggestion-page.vue` | 提案を1件ずつ捌く |
| 付いているタグ | `src/client/pages/views/attached-tag.vue` | タグ1つの見た目。gkill 本体と同じ |
| 星 | `src/client/pages/views/saihate-stars-overlay.vue` | ダークテーマの背景 |
| 雪 | `src/client/pages/views/snow-fall-overlay.vue` | ライトテーマの背景 |

## 2. 器（App.vue）

### 状態

| 名前 | 型 | 意味 |
| --- | --- | --- |
| `is_checked` | boolean | ログイン状態を確かめ終えたか。**偽の間は何も描かない** |
| `is_authenticated` | boolean | ログイン済みか |
| `logged_in_user_id` | string | 誰として入っているか |
| `is_analyzable` | boolean | そのアカウントが解析の対象か |

### 描くもの

```
<div>
  星（ダークのとき） / 雪（ライトのとき）
  <v-app>
    is_checked のとき:
      is_authenticated → 提案画面
      それ以外          → ログイン画面
  </v-app>
</div>
```

### 落とし穴

**`.v-layout--full-height { background-color: #0000 }` が唯一の透過スイッチです。**
Vuetify は `.v-application` に地の色を塗るので、透明にしないと背後の降りもの
（`z-index: -100000000`）が完全に隠れます。

## 3. ログイン画面

### 項目

| 項目 | 種別 | 属性 |
| --- | --- | --- |
| 利用者ID | テキスト | `autofocus`、`autocomplete="username"` |
| パスワード | パスワード | `autocomplete="current-password"`、Enter で送信 |
| エラー | 警告 | `role="alert"`。失敗したときだけ出る |
| 入るボタン | ボタン | 送信中は `loading` |

### 振る舞い

| 事象 | 動き |
| --- | --- |
| 送信 | パスワードをブラウザの中で SHA-256 にしてから送る |
| 送信中 | 入力欄とボタンを無効にする（二重送信の防止） |
| 成功 | パスワード欄を空にし、セッションを聞き直す |
| 失敗 | 文面を出してその場に留まる |
| 安全でない接続 | 「https:// か localhost で開いてください」。**平文を送らない** |

画面の下に「この画面には未確認の提案が並びます。人に見られる場所では開かないでください」
という注意を常に出しています。

## 4. 提案画面

### 4.1 上の帯

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| 表題 | 「タグ提案」 | |
| 利用者ID | ログインしている人 | 複数アカウントの取り違え防止 |
| 確認待ち | 未判定の件数 | 確定するたびに更新 |
| 解析ボタン | 解析を1回走らせる | **対象外の利用者では押せない** |
| 読み直しボタン | 一覧を取り直す | |
| テーマボタン | 星と雪を切り替える | クッキーに覚える |
| ログアウト | ログイン画面へ | |

### 4.2 本体（状態ごと）

| 状態 | 出るもの |
| --- | --- |
| 読み込み中 | 回転する印 |
| 対象外 | 「このアカウントは解析の対象に含まれていません」＋ `--user <利用者ID>` の案内 |
| 空 | 「確認待ちの提案はありません」＋ 更新ボタンの案内 |
| 判定中 | 記録カード（下記） |

### 4.3 記録カード

| 区画 | 項目 | 備考 |
| --- | --- | --- |
| 進み具合 | `3 / 12` | 右寄せ |
| 写真 | 中継した画像 | 写真の記録のときだけ。最大 45vh |
| 見出し | 時刻 ・ 種別 | 薄い字 |
| 本文 | 記録の本文 | 折り返す。最大 20vh でスクロール |
| 付いているタグ | タグの並び | 無ければ「なし」 |
| 案内 | 「付けるタグを選んでください。複数選べます。**何も選ばずに確定すると「タグ不要」として記録します**」 | |
| 候補 | タグの札 | 番号つき。選ぶと塗りつぶしになる |
| 根拠 | `タグ名: 理由（段階）` | 薄い字。候補ごとに1行 |
| 自分で足す | 入力欄＋追加ボタン | Enter でも追加 |
| 操作 | 「タグ不要 (x)」「確定 (Enter)」 | 左右に分ける |
| 補足 | キー操作の一覧 | 中央 |

候補の札には確信度を百分率で添えます（`82%`）。

### 4.4 通知

右上に積みます。

| 種類 | 消え方 |
| --- | --- |
| 成功 | 2.5秒で自動的に消える |
| 失敗 | **消えない**（閉じるボタンで消す） |

失敗を残すのは、見逃すと同じ操作を繰り返すことになるためです。

## 5. 付いているタグの見た目

gkill 本体の `attached-tag` をそのまま写しています。**丸い角と、左端の punch-hole**
（`::before` に `・` を置いたもの）が特徴です。

同じ記録を gkill と確認画面の両方で見たときに、**同じものに見えること**を狙っています。

## 6. 降りもの

| テーマ | 降るもの | ファイル |
| --- | --- | --- |
| ダーク | 星 | `saihate-stars-overlay.vue` |
| ライト | 雪 | `snow-fall-overlay.vue` |

gkill 本体から引き継いだものです。実装上の注意は2つあります。

- `<style>` に **scoped を付けられません**（動的に生成する DOM に scope 属性が付かない）
- `onUnmounted` で**タイマーを必ず解除します**。テーマ切替が `v-if` なので、
  解除しないとループが多重化して流星が増え続けます

## 7. キー操作

| キー | 動き |
| --- | --- |
| `j` / `↓` | 次の記録へ |
| `k` / `↑` | 前の記録へ |
| `1`〜`9` | その番号の候補を選ぶ／外す |
| `Enter` | 確定（**何も選んでいなければタグ不要**） |
| `x` / `Delete` | タグ不要として確定 |

**反応しない条件**（誤爆を防ぐため）:

- 文字を打っている最中（`input` / `textarea` / `contenteditable` に焦点がある）
- 修飾キー（Ctrl / Meta / Alt）が押されている
- 変換中（`isComposing`）
- キーの押しっぱなし（`repeat`）

記録の一定割合は元々タグが要らないので、**`x` が最短の操作になるようにしてあります**。

## 8. 配色

gkill 本体の値を引き継いでいます（`src/client/plugins/vuetify.ts`）。

| | ライト | ダーク |
| --- | --- | --- |
| テーマ名 | `gkill_theme` | `gkill_dark_theme` |
| primary | `#2672ed` | 同左 |

スクロールバーもテーマ色に追従させています（`--gkill-scrollbar-*`）。

## 9. 応答性

| 幅 | 見え方 |
| --- | --- |
| 広い | カードは最大 720px で中央 |
| 狭い | カードが幅いっぱいに広がる |

写真は `max-height: 45vh`、本文は `max-height: 20vh` で抑えているので、
1件が画面に収まり、確定ボタンまでスクロールせずに届きます。

## 10. PWA としての見え方

| 項目 | 値 |
| --- | --- |
| 名前 | gkill タグ提案 |
| 短い名前 | タグ提案 |
| 表示 | `standalone`（ブラウザの枠が消える） |
| 向き | `portrait` |
| テーマ色 | `#2672ed` |
| 背景色 | `#ffffff` |
| アイコン | 192 / 512 / maskable 512 |

アイコンは `src/tools/build_icons.mjs` が依存なしで描いています。
青い角丸の四角に、白いタグの輪郭と穴。**記録の中身は一切含みません。**
