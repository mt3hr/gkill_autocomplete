# 使い方（利用者向け）

gkill に溜まった記録に、**付けるべきタグを提案する**ツールです。

**提案するだけで、自分では書き込みません。** タグが付くのは、
あなたが確認画面で承認したときだけです。

## 1. 何ができるか

- まだタグの付いていない記録を見つけて、付けるべきタグを提案します
- 提案は確認画面に並び、1件ずつ承認・却下できます
- 判定は**同じ端末の LLM** で行います。記録が外へ送られることはありません

### 何をしないか

- 勝手にタグを付けることはありません
- まとめて承認する手段はありません（1件ずつ見ないと誤りが混ざるため）
- タグを新しく作ることはありません（あなたが過去に使ったタグから選びます）

## 2. 用意するもの

| 要るもの | 備考 |
| --- | --- |
| 稼働中の gkill | **同じ端末で動いていること** |
| ローカルの LLM | Ollama など。無くても本文の一致だけで動きます |

## 3. はじめかた

### 3.1 設定を作る

```
gkill_autocomplete init --user <あなたの利用者ID>
```

**パスワードは要りません。** gkill と同じ端末で動かすこと自体が、権限の根拠になります。

このコマンドは、あなたの gkill を読んで「どこで、どんなふうにタグを付けているか」を
調べ、それに合った設定を作ります。使える LLM のモデルも調べて書き込みます。

作られる場所: `%USERPROFILE%\gkill_autocomplete\config.json`

### 3.2 解析する

```
gkill_autocomplete --user <あなたの利用者ID> --once
```

まだタグの付いていない記録を調べて、提案を作ります。
**時間がかかります**（写真の判定は1件あたり数分かかることがあります）。

はじめは短い期間で試すことをお勧めします。設定の `candidate_days` を
`2` くらいにしておくと、すぐ終わります。

### 3.3 確認する

```
gkill_autocomplete --user <あなたの利用者ID>
```

画面が開く場所が表示されるので、ブラウザで開いてください。
gkill の利用者IDとパスワードでログインします。

## 4. 画面の使い方

キーボードだけで捌けます。

| キー | 動き |
| --- | --- |
| `Enter` | 選んだタグを付けて次へ |
| `x` | **タグ不要**として次へ |
| `1`〜`9` | 候補のタグを選ぶ（複数選べます） |
| `j` / `k` | 次へ / 前へ |

### 「タグ不要」を使ってください

**すべての記録にタグが要るわけではありません。** 記録の一定割合は、
元々そのままでよいものです。

`x` を押すと「この記録にタグは要らない」として覚え、**二度と提案しません**。
これが最短の操作になるようにしてあります。

### 候補に無いタグを付けたい

「自分でタグを足す」の欄に入力して追加すれば、そのタグを承認できます。

### 判断に迷ったら

候補の下に「なぜそう思ったか」が出ています。

| 表示 | 意味 |
| --- | --- |
| `text_match` | 同じ本文の記録に、過去このタグが付いていた |
| `context` | 近い時刻の記録や、本文の中にそのタグ名が現れた |
| `llm` | LLM が写真や本文を見て判断した |
| `rule` | あなたが設定に書いたルール |

`text_match` は強い手がかりです。`llm` は当たり外れがあります。

## 5. ホーム画面に入れる（スマートフォン）

画面はアプリのように使えます。ブラウザのメニューから
「ホーム画面に追加」「アプリをインストール」を選んでください。

**先に証明書を信頼させる必要があります。** 詳しくは
[運用の手引き](operations-guide.md)の3章を参照してください。

なお、**電波が無いところでは画面が開くだけで、中身は出ません**。
記録の中身を端末に残さないようにしているためです。

## 6. うまくいかないとき

| 症状 | どうするか |
| --- | --- |
| 「利用者を指定してください」と出る | `--user <あなたの利用者ID>` を付けてください |
| 「先に gkill を起動してください」と出る | gkill を一度起動してから、もう一度試してください |
| ブラウザが警告を出す | 証明書に載っている名前で開いてください（[運用の手引き](operations-guide.md) 3.1） |
| ログインできない | 15分に5回までです。少し待ってください。**gkill には入れます** |
| 提案が空で「対象に含まれていません」と出る | そのアカウントを `--user` で指定して起動しなおしてください |
| 提案が0件 | 解析ボタン（右上の更新）を押してください |
| 解析が終わらない | LLM が重いことがあります。設定の `candidate_days` を短くしてください |
| 承認したのにタグが付かない | 過去に同じタグを付けて手で消した記録です。**わざと蘇らせません** |
| 同じ記録が何度も出る | 保存先に書けていない可能性があります |

## 7. 提案をやり直したい

設定を変えたあと、その設定で付け直したいときは次を実行します。

```
gkill_autocomplete reset --user <あなたの利用者ID>
```

**承認・却下・タグ不要の判定は消えません。** 却下したものが復活することはありません。

## 8. 大事にしてほしいこと

### バックアップ

```
%USERPROFILE%\gkill_autocomplete\gkill_autocomplete.db
```

**このファイルだけは失うと戻りません。** あなたが下した判定
（承認・却下・タグ不要）が入っており、これらは作り直せません。

設定ファイルは `init` で作り直せます（手で調整した分は戻りませんが）。

### 画面を開く場所

確認画面には**未確認の提案、つまりあなたの記録の中身がそのまま並びます**。
人に見られる場所では開かないでください。

### 外へ出ないもの

| | |
| --- | --- |
| 記録の本文と写真 | 手元のブラウザと、同じ端末の LLM だけ |
| パスワード | ブラウザの外に平文で出ません |
| 通信先 | gkill とローカル LLM の2つだけ。テレメトリも更新チェックもありません |

## 9. 毎日使うなら

解析を定期実行に登録しておくと、朝まとめて確認できます。

```
gkill_autocomplete --user <あなたの利用者ID> --once
```

**パスワードを渡さなくてよいので、タスクスケジューラの設定に秘密が残りません。**

Windows ならタスクスケジューラ、Linux なら cron や systemd timer に登録します。
