# 用語集

この資料集で使う語を定義します。最初に読んでください。

例示に出てくるタグ名・リポジトリ名はすべて架空のものです。

語がどこで使われるかは、[README.md](README.md) の依存関係図を参照してください。

## 1. 基本概念

| 用語 | 定義 |
| --- | --- |
| **記録** | gkill に保存されている出来事1件。写真・メモ・金銭記録・時間計測など、種別はいろいろある。gkill 側の呼び名とは別に、この資料では一貫して「記録」と呼ぶ |
| **タグ** | 記録に付ける短い分類の語。1つの記録に0個から複数個付く |
| **提案** | 「この記録にはこのタグが付くのではないか」という推測1件。提案しただけでは gkill に何も書き込まれない |
| **判定** | 提案に対して人が下した結論。承認・却下・タグ不要の3つがある。**再生成できない情報** |
| **確信度** | 提案がどれくらい確からしいかを 0〜1 で表した値。閾値未満の提案は表に出さない |
| **段階** | 判定の手順の層。上の段階で決まれば下は見ない。[requirements.md](requirements.md) と [activity-diagrams.md](activity-diagrams.md) 参照 |
| **利用者** | gkill のアカウント。同じ人でもアカウントごとに別のリポジトリを持つので、提案も**アカウント単位で完全に分ける**。[er-diagram.md](er-diagram.md) 参照 |

## 2. 学習に関する用語

| 用語 | 定義 |
| --- | --- |
| **文脈** | 学習と候補抽出の単位。写真はリポジトリの種別、それ以外は記録の種別で分ける。`rep:SampleRep` や `type:kmemo` の形で表す |
| **リポジトリ種別** | リポジトリ名の先頭部分。gkill のリポジトリ名は「種別_端末_日付」の形なので、先頭を取れば端末を買い替えても同じ文脈にまとまる。`SampleRep_DeviceA_20200101` なら `SampleRep` |
| **候補タグ** | その文脈で実績のあるタグのうち、判定にかけるもの。全タグを総当たりせず、ここで絞る |
| **実績件数** | その文脈でそのタグが使われた回数。これが `min_examples` に満たないタグは候補にならない |
| **参考例** | 候補タグ1つにつき数件だけ選んだ過去の記録。LLM に「このタグの記録はこう見える」と示すために使う。学習済みモデルも埋め込みの索引も持たない |
| **タグ無し率** | その文脈で、タグを1つも付けないまま残された記録の割合。「付けない」という選択の起こりやすさを表す |

## 3. 判定に関する用語

| 用語 | 定義 |
| --- | --- |
| **逐語一致** | 本文が過去の記録と字面で一致すること。空白と改行の揺れ、英字の大小だけを吸収して比べる |
| **近傍の記録** | 判定したい記録の前後、指定した時間内にある別の記録。対になる記録が数秒差で並ぶことがあり、片方の見出しがもう片方の手がかりになる |
| **multi-label** | 候補タグごとに独立して当否を決めるやり方。最も確からしい1つを選ぶのではないので、結果は0個にも複数個にもなる |
| **タグ不要** | 「この記録にタグは要らない」という記録単位の判定。一度そう決めたら二度と提案しない |

## 4. 実装に関する用語

| 用語 | 定義 |
| --- | --- |
| **決定的な識別子** | (記録のID, タグ名) から計算で導く UUID。乱数を使わないので、何度解析し直しても同じ組み合わせには同じ値が割り当たる。再解析での重複と、却下したものの復活を同時に防ぐ |
| **派生データ** | 解析し直せば作り直せるもの。提案そのものと「判定済みの印」が該当する |
| **人間の判定** | 承認・却下・タグ不要の記録。**再生成できない**ので、派生データを掃除するときも消さない |
| **確認画面** | 提案を1件ずつ承認・却下する画面。gkill_autocomplete 自身が配信する。gkill のアカウントでログインし、通信は gkill と同じ証明書で暗号化される。PWA なのでホーム画面に入れられる |

## 5. 外部との関係

| 用語 | 定義 |
| --- | --- |
| **gkill** | 記録の保存先。gkill_autocomplete は gkill 本体を一切変更しない。ただし認証だけは gkill のコードを import して使う（照合を写し取るとずれたときに静かに弱くなるため） |
| **衛星リポジトリ** | gkill の公開 API だけを使う独立したツール群のこと。gkill_autocomplete もその1つ |
| **ローカル LLM** | 同じ端末で動く LLM。OpenAI 互換の口を持つものであれば実装は問わない。接続先がループバック以外の場合は起動を拒否する |
| **ローカルセッション** | gkill を叩くための資格情報。gkill にログインするのではなく、**gkill の設定ディレクトリへ直接書いて発行する**。有効期間は1週間で、使っている間は自動で取り直す。信頼の根拠は「同じ端末で設定ディレクトリに書けること」 |
| **スキーマ版の確認** | `account.db` を開く前に版を読む検査。旧版を開くと gkill 側が自動移行を走らせ、**全アカウントのパスワードが無効化される**ため、現行版でなければ何もせず止まる |

## 6. 主要ファイルの対応

| 概念 | 実装 |
| --- | --- |
| 設定とその検証 | `src/autocomplete/internal/config/` |
| 認証（照合・セッション・TLS） | `src/autocomplete/internal/gkillauth/` |
| gkill との通信 | `src/autocomplete/internal/gkillclient/` |
| 提案と判定の保存 | `src/autocomplete/internal/store/` |
| 決定的な識別子 | `src/autocomplete/internal/ids/` |
| 学習と判定 | `src/autocomplete/internal/suggest/` |
| LLM への問い合わせ | `src/autocomplete/internal/llm/`、`src/autocomplete/internal/classify/` |
| 全体の配線 | `src/autocomplete/internal/app/` |
| 確認画面の配信 | `src/autocomplete/internal/websrv/` |
| 確認画面 | `src/client/` |
